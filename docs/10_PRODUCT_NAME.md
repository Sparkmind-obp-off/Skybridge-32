# Skybridge 32 — Product Name

## Primary name

**Skybridge 32**

## Descriptor

**Personal 5K Race Coach**

## Why

- directly tied to the race;
- memorable;
- communicates the 32-day preparation window;
- personal rather than generic;
- does not imply a broad fitness platform.

## Alternatives

- Skybridge Coach
- Run to Skybridge
- SB32
- Skybridge Ready

## Recommendation

Use **Skybridge 32** for the repository, PWA title, documentation and internal product identity.
