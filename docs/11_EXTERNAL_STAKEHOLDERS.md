# Skybridge 32 — External Stakeholders

## 1. Race organizer

The organizer is the authoritative source for:

- race rules;
- route;
- COT;
- start time;
- race-pack collection;
- water stations;
- safety procedures;
- venue instructions;
- last-minute changes.

App assumptions must never override official communication.

## 2. User / runner

The runner supplies the most important real-world feedback:

- session completion;
- RPE;
- soreness;
- actual duration;
- optional distance;
- perceived comfort;
- motivation;
- race-readiness.

## 3. Optional future providers

Weather provider, fitness platform or AI provider may be added later, but none is required for V0.

## 4. Decision hierarchy

When information conflicts:

1. official organizer instruction;
2. current real-world user state;
3. conservative product rules;
4. historical assumptions/documentation.

## 5. Scope rule

No external stakeholder is required to make V0 useful.
